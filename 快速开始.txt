原神陀螺仪助手 · GenshinGyro v1.4.0   快速开始
================================================================

一、先装驱动（只需一次，但绕不过去）

  虚拟手柄不是软件画出来的，是 ViGEmBus 这个内核驱动造出来的设备。
  没装它，程序能打开、界面能动，但永远不会有虚拟手柄。

    1. 打开 https://github.com/nefarius/ViGEmBus/releases
    2. 下载 ViGEmBus_*.exe 并安装（需要管理员权限）
    3. 提示重启就重启

  另外两个按需准备：
    * VIIPER —— 只有「转发到虚拟 DualSense」和「PS5 手柄原生震动」需要它。
      到 https://github.com/alia5/VIIPER/releases 下载 VIIPER-*-x64.exe，
      放到 GenshinGyro.exe 旁边（或它的上一级目录）即可，程序会自己启动它。
    * HidHide —— NS 模式必须，其它情况见第四节。

二、打开程序

  双击「GenshinGyro.exe」。

  如果 Windows 弹「Windows 已保护你的电脑 / 未知发布者」：
  点「更多信息」→「仍要运行」。exe 没有数字签名，这是必然结果，不是文件有问题。

  想要控制台模式（不弹窗口、直接转发）就打开 cmd，cd 到本目录：
      GenshinGyro.exe --cli                        整机转发（自动识别手柄）
      GenshinGyro.exe --cli --source ds4           实体 DS4 全量转发
      GenshinGyro.exe --cli --source ds4 --motion-only
                                                   仅体感 + Share 当触控板
      GenshinGyro.exe --cli --source ds4 --no-virtual-pad --verbose
                                                   只唤醒手柄体感、不建虚拟手柄（诊断）

三、界面说明

  [顶部]  ●  状态文字（手柄型号 · 链路 · 报文速率）          转发：开启 / 关闭

          那枚 ● 的含义：
            亮绿呼吸  = 正在转发
            暗绿      = 手柄连着，但没开转发
            红色      = 没有手柄

  [实时读数]
          按键：当前按下了哪些键
          字节：原始按键字节（排查映射时看这里）
          电量：8/8 就是满的
          陀螺仪 °/s：三个轴的角速度，静止时应接近 0
          重力 g：三个轴的加速度，平放时 Z 轴约 1.0

  [输出模式]
          输入手柄                     自动 / Switch Pro / DualShock4
          完整转发到虚拟 DualShock 4    ← 开关
          虚拟手柄只转发体感            ← 开关
          转发到虚拟 DualSense 手柄     ← 开关
          × 与 ○ 互换，□ 与 △ 互换     ← 开关

          前三个是转发模式，**互斥**，只能开一个；三个都关 = 只看数据，不建虚拟手柄。
            * 完整转发    → 虚拟 DualShock 4（原神的常规用法）
            * 仅体感      → 虚拟手柄只发体感，按键摇杆留给实体手柄
            * 虚拟 DualSense → 内容与"完整转发"一样，虚拟手柄换成 PS5 那只

          第四个「× 与 ○ 互换，□ 与 △ 互换」和转发模式**互不排斥**，
          两个虚拟手柄上都能用：它只交换虚拟手柄的两对面键，用在不习惯当前
          按键布局的游戏里。只动这四个键，十字键、肩键、扳机、Share 都不受影响；
          连按两次等于没动。

  [体感调节]
          体感灵敏度    0.1 – 10.0。1.0 = 和实体手柄完全一致；
                        调大转视角更快，调小更稳。它只缩放角速度，
                        重力保持原样，所以游戏判断倾斜依然准。
          死区补偿      俯仰 / 偏航 / 滚转，各 0.0 – 5.0 °/s，默认 0.0。
                        原神对陀螺仪有个很小的死区，慢速转动视角不动。
                        这里填的值会在你真实转动的方向上叠加一个固定量，
                        把慢速转动抬过游戏死区。建议从 0.5 – 2.0 试。
                        只有该轴速率超过 0.5 °/s 才补偿，所以手放桌上不会自己漂。

  [PS5手柄原生震动]
          开启震动                     ← 总开关
          震动强度  + 左右分工          ← 总倍率 / 两个马达是否分工
          灵敏度 / 起振 / 拖尾 / 轻音过滤 / 响应曲线 / 低频高频分界
                                       ← 六个滑块，每个下面都有一行说明

          它是怎么震的：程序建一台虚拟 DualSense（没有就只建音频那部分），
          游戏把"触觉音频"写到它的音频端点，程序读回来驱动你手里的实体手柄。
          四种组合都验过：DS4 / NS Pro × 有线 / 蓝牙。

          常用调法：
            * 没反应 → 先把「灵敏度」调大
            * 太糊/太拖 → 「拖尾」调小（30ms 一下就停）
            * 背景音一直在抖 → 「轻音过滤」调大
            * 调乱了 → 卡片右下角「恢复默认」

          开关本身就有记忆；只有开关打开时才会去准备音频端点，关掉即拆。
          转发模式的切换、手柄掉线都不会影响它。

          以上设置（转发模式、四个体感数值、键位互换、震动十个参数）
          都会被记住（存在 exe 旁边的 settings.json），下次打开自动沿用。
          删掉 settings.json 即恢复默认。

四、原神怎么配：看原神的反应，不看有线还是蓝牙

  插上手柄、进原神，先看它是什么反应，再对号入座：

    原神的表现                          该开哪个             HidHide
    ------------------------------------------------------------------
    按键和体感都正常                    不用本软件           —
    认按键、体感不动                    仅体感               不要
    键值错乱、根本没法控制（NS 模式）   完整转发             必须
    完全没反应、什么都读不到            完整转发             不要

  一句话记：HidHide 只在"原神看得见但读错"的时候才需要。
    看得见但读错  → 必须藏（NS 模式都这样）
    根本看不见    → 不用藏
    要用它读按键  → 不能藏（"仅体感"那种情况）

  ★ 「输入手柄」那一栏也要选对：NS 模式手柄选「Switch Pro」，DS4 模式选「DualShock4」，
    不确定就留在「自动」。
  ★ Share 会被映射成触控板按下：蓝牙模式下触控板按键不灵，这是最靠得住的位置。
  ★ 经验：DS4 模式的手柄先试有线直连，原神有可能本来就认（按键体感都正常），
    那就完全不需要本程序。山弯 Q34U 的 DS4 模式有线直连就是这样。
  ★ 想要震动的就开「转发到虚拟 DualSense」和「开启震动」——震动只在 DS5 这条路上有。

五、HidHide（NS 模式必须，其它情况看上一节）

  HidHide 是一个过滤驱动 + 配置工具，能把指定的实体手柄从别的程序眼里"藏"起来。

  为什么 NS 模式必须用它：原神会把 NS 模式手柄识别成错误的东西，导致键值错乱、
  完全没法操作（不是读不到，而是读错）。把实体手柄藏起来，原神就只会看到虚拟手柄。

  为什么"仅体感"不能用它：那种情况要靠实体手柄出按键，藏了就一起没了。

  步骤：
    1. 安装 HidHide：https://github.com/nefarius/HidHide/releases（管理员权限，装完重启）
    2. 打开 HidHide Configuration Client
    3. Devices 页：勾选你的实体手柄
    4. Applications 页：把 GenshinGyro.exe 加进白名单
       （不加的话，本程序自己也会看不到手柄）
    5. 勾选启用隐藏，然后重新打开本程序

  改完 HidHide 一定要重开本程序：手柄的可见性在打开设备的那一刻就确定了。

六、常见问题

  * 一直显示未连接 → 按一下手柄任意键唤醒它；确认手柄已经在 Windows 设置里配对过。
  * 体感忽然没了、按键摇杆正常 → 手柄退回了"最小报文"模式（重连、休眠唤醒后常见）。
    程序会自动重新请求扩展报文；恢复不了就关掉重开一次。
  * 游戏里按键乱跳 / 完全没法控制 → 该藏却没收：NS 模式必须用 HidHide 隐藏实体手柄，
    否则原神同时读两路输入。检查 Devices 勾了没有、Applications 里加了 GenshinGyro.exe 没有，
    改完重开本程序。
  * 开了震动但手柄不震 → 看界面底部那行状态：
      写「关闭」        = 开关没开，或上次建不出音频端点被自动关了（状态行会写原因）
      写「等待手柄」    = 手柄没被程序拿到，按一下手柄任意键
      写「已开启（…）」 = 一切正常，那就是游戏本身没往这个端点写触觉音频；
                          原神会写，大多数别的 PC 游戏只发普通 rumble 报文，收不到
    两个功能同时开时系统里会有两台同名「扬声器 (DualSense …)」端点，
    游戏可能挑错那台：把震动开关关一下再开，程序就会复用虚拟手柄那台。
  * 提示「没找到 VIIPER-*.exe」 → 按第一节把 VIIPER 放到 GenshinGyro.exe 旁边。
  * 和 DS4Windows / Steam 冲突 → 同一只手柄同时只能被一个程序独占读取。
    测试和游玩时请只运行本程序，并关掉 Steam 对该游戏的输入接管。
